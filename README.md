# 🚀 SkillGap

SkillGap is a smart productivity-focused mobile application built using Flutter that helps students identify free gaps between lectures and utilize that time effectively for learning and self-growth.

---

## 📌 Problem Statement

Students often have free time between lectures but fail to utilize it productively. This app solves that by detecting gaps in the timetable and suggesting opportunities to use that time efficiently.

---

## ✨ Features

- 📅 Timetable Management  
- ⏱️ Automatic Gap Detection between lectures  
- ❌ Cancel Lecture Support  
- 📊 Gap Count Display (per day)  
- 🎯 Clean and Minimal UI  
- 💾 Local Storage using Hive  

---

## 🛠️ Tech Stack

- Flutter  
- Dart  
- Hive Database  

---

## 🧠 How It Works

1. User adds their timetable  
2. App filters today's lectures  
3. Gap Detection Algorithm identifies free time slots  
4. Displays all available gaps in a clean UI
